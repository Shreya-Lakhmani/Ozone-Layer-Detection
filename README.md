# Ozone-Layer-Detection-and-Forecasting-using-Data-Analysis-and-Machine-Learning

The main objective of this project is to predict ozone levels using Random Forest Classifier techniques and analyze the environmental factors that influence ozone formation. The system helps in identifying whether ozone levels will be high or low based on meteorological data such as temperature, humidity, wind speed, and pressure.


⚙️ Installation & Setup

1️⃣ Clone the Repository

git clone https://github.com/Shreya-Lakhmani/Ozone-Layer-Detection.git

cd ozone-prediction-app

2️⃣ Install Dependencies

pip install -r requirements.txt

3️⃣ Run the App

streamlit run app.py

Try the deployed app here:
